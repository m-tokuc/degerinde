# 🚗 Degerinde - End-to-End MLOps Car Pricing Engine

**Degerinde**, araç özelliklerine (marka, model, yıl, km, vites vb.) göre piyasa değerini makine öğrenmesi algoritmalarıyla tahmin eden ve canlıya alınmaya hazır full-stack bir MLOps platformudur.

## 🏗️ Proje Mimarisi & Teknolojiler
* **Machine Learning:** Python, XGBoost (3 farklı mimari arasından seçilmiş fiyatlandırma motoru)
* **Backend:** FastAPI (Yüksek performanslı Asenkron REST API)
* **Frontend:** Next.js / React (Modern kullanıcı arayüzü)
* **DevOps & Infrastructure:** Docker & Docker Compose
